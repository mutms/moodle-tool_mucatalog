# Universal catalogue plugin for Moodle™ LMS

![Moodle Plugin CI](https://github.com/mutms/moodle-tool_mucatalog/actions/workflows/moodle-ci.yml/badge.svg)

A unified catalogue of courses, programs, and certifications for standard Moodle™ LMS installations
— fully open source under GPL 3.0, with no restrictions on commercial use. Part of the
[MuTMS suite](https://github.com/mutms).

Provides a single browsable catalogue combining courses, Programs, and
Certifications. Access is controlled by visibility flags and cohort membership, with full
compatibility with MuTMS multi-tenancy — each tenant may have their own catalogue content.

> **Preview release** — this plugin is not yet registered in the Moodle plugins database.
> The API and features will change before the stable release.

## Features

* Unified catalogue of courses, programs, and certifications in one place
* Access control based on visibility flags and cohort membership
* Multi-tenancy aware

## Requirements

Required plugins:

* [Additional tools library plugin](https://github.com/mutms/moodle-tool_mulib)
* [Programs plugin](https://github.com/mutms/moodle-tool_muprog) *(if using programs)*
* [Certifications plugin](https://github.com/mutms/moodle-tool_mucertify) *(if using certifications)*
